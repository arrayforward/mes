# H5 剧本:质量与法规追溯(pb3 人工版)

> **定位**:面向 H5 验证台的剧本式操作说明,是自动化剧本
> `mse/tools/pb3_quality_compliance.py`(35 项校验)的**人工操作版**——人照着 UI 能点出
> 与脚本相同的结果。全程只用浏览器界面(不发 API、不碰数据库),每步给出**预期结果**
> 与**结果说明**(这步验证了什么系统机制)。
> **剧情**:法规审核周。VIN-QC01 上线,检验计划与任务先行;检测线设备上传
> 尾气/大灯/淋雨数据,其中一条"淋雨不合格"是设备误传,修正留痕;一条误录
> 缺陷被作废(缺陷累计口径不回减);两个法规件批次绑定上车,正向追踪与
> 反向追溯双向可走;严重缺陷触发自动锁车,缺陷车辆不出厂。
> **配套**:主流业务的一天见《H5业务流模拟操作手册.md》;异常/边界专项见
> 《H5人工验证测试方案.md》;脚本化回归见《剧本自动化回归.md》。

> **UI 与脚本的形态差异**(与 pb2 手册同一约定):脚本的批次绑定是一条双目标

> "模糊文本(自由输入)"填原文,二者同为"模糊空间原文照存、永不改写"。

## 第三幕 误录缺陷作废与累计口径(质检员→质检长,10:00)

## 结果总览(演完后的系统状态)

- 检测数据、缺陷、锁定、批次绑定全在事件树;误传/误录的修正与作废带 corrects 同列可查;
- 两个口径并排演示:终态覆盖(淋雨结论修正后取新值)与累计不回减(缺陷总数);
- 触发规则的锁车与人工事件同权——都过四层校验;
- F14 遍历双向可走,法规件召回定位零额外索引。

## 常见问题

- **行内没有 InspectionDataCorrected 按钮**:确认在 V-QUALREC-F12 流水里点的是误传那条行;修正按钮只挂在能被它修正的事件行上,corrects 由服务端自动带。
- **DefectCancelled 在哪点**:它不在任何视图的行上,用顶部「+发起事件」从全类型表里选,corrects 手填误录事件号。
- **数据想重来**:停服务器删两个 db 文件即可(本剧本不依赖 demo 背景)。
