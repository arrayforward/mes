# H5 剧本:运维与集成(pb5 人工版)

> **定位**:面向 H5 验证台的剧本式操作说明,是自动化剧本
> `mse/tools/pb5_ops_integration.py`(38 项校验)的**人工操作版**——人照着 UI 能点出
> 与脚本相同的结果。全程只用浏览器界面(不发 API、不碰数据库),每步给出**预期结果**
> 与**结果说明**(这步验证了什么系统机制)。
> **剧情**:运维值班夜。ERP 报文进出集成接口,一条误报文作废留痕;两台设备
> 上台账,一台误报状态被修正;PLC 网关经适配层上报工位占用(信任分级 +
> 异步结算,落账才成事实);车间 OEE 三率一填即派生;午夜模拟断电——
> 停库重启后事件/视图/定义原样都在,幂等键跨重启不重复入账。
> **配套**:主流业务的一天见《H5业务流模拟操作手册.md》;异常/边界专项见
> 《H5人工验证测试方案.md》;脚本化回归见《剧本自动化回归.md》。
> **特殊道具**:第六幕"崩溃恢复"与第七幕"幂等跨重启"需要 `stop_mes.bat` /
> `start_mes.bat` 配合(脚本里是 Server.stop()/restart() 自动完成);
> 第三幕"PLC 信任分级"需要在顶部**凭证框**切换 `ui-token` / `plc-gw-token` / 清空。

## 第三幕 PLC 适配层:信任分级 + 异步结算(凭证框切换,22:15)

**剧情**:PLC 网关经适配层上报"工位01 占用"。先演示无凭证被拦,再换网关凭证
入队,手动落账成事实,最后配平一条"空闲"。
**本幕在顶部凭证框切换:`ui-token` / 清空 / `plc-gw-token`。**

| 步 | 操作 | 预期结果 | 结果说明 |
|---|---|---|---|
| 3.1 | 顶部**凭证框清空**;点「+发起事件」选 `PlcEdgeReported`(事件类型旁标 `min_trust=1`):id=`工位01`、actor=`plc-gw`、工位占用=`占用`,提交 | **红色拦截回执**,layer=2:"信任级不足: PlcEdgeReported 要求 >=1";事件流无新增 | L2 信任分级:高频机器信号只信网关级及以上凭证;无凭证(信任级 0)连形式校验都过不了 |
| 3.2 | 凭证框填 `plc-gw-token`,原样再提交 | **蓝色回执 accepted**,queue_seq=N;回执内出现「落账(POST /drain)」按钮;**右侧事件流还看不到这条事件** | 异步结算:settlement=async 的类型四层校验后入队,已验未结——结算边界清晰可见 |
| 3.3 | 点回执里的「落账」(或顶部「落账」按钮) | toast"落账完成 drained≥1";事件流出现 `PlcEdgeReported` | drain = 队列串行落账,此刻才成事实 |
| 3.4 | 保持 `plc-gw-token`,点「+发起事件」选 `PlcEdgeVoided`:id=`工位01`、actor=`plc-gw`、工位占用=`空闲`,提交 | settled(同步结算) | 修正配平:PlcEdgeVoided 同样 min_trust=1;工位占用值域 ∈ {空闲, 占用} |
| 3.5 | 凭证框填回 `ui-token` | —— | 后续剧情用回默认凭证;注:`ui-token`(L2)提交 PlcEdgeReported 同样受理——门槛是 ≥1,清空(0)才被拦 |

## 结果总览(演完后的系统状态)

- 集成报文、设备台账、PLC 迁移沿、OEE 派生全是同一套事件语义;误报/误传都有修正配平;
- 信任分级(清空被拦 / 双凭证受理)与异步结算(accepted→落账)在一条 PLC 事件上同框;
- 停库重启后:事件逐条一致、视图渲染一致、定义完好、幂等键不重复入账——**事件树是唯一真相**。

## 常见问题

- **提交 PlcEdgeReported 没有 accepted 只有拦截**:看凭证框——清空是信任级 0,必拦;填 `plc-gw-token`(或 `ui-token`)再试。
- **accepted 之后事件流里找不到**:那是已验未结,点「落账」后才入树。
- **凭证框改完不生效**:凭证持久化在浏览器 localStorage,改完即随下一个请求生效;别忘了演完第三幕填回 `ui-token`。
- **数据想重来**:停服务器删两个 db 文件即可(本剧本不依赖 demo 背景)。
