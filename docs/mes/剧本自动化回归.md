# 剧本自动化回归:H5 验证台的可执行回归网

> **定位**:`mse/tools/` 下的五本 Python 剧本是 H5 验证台的**可执行回归**——脚本发的
> 就是界面同一批 HTTP 请求(`POST /events`、`GET /views/{id}`、`GET /meta/events`、
> `POST /drain`),断言的就是手册里"预期结果"列写的东西。界面能点出来的,脚本就能
> 验出来;脚本验不过的,界面上也一定能复现。
> **人工对照**:五本剧本的操作手册/测试方案见文末 §6 对照表。

## 2. 运行方法

### 前置

- 已构建 `mse/build/mse_server.exe`(CMake 构建;release 包的 exe 亦可)。
- 服务器程序查找顺序:环境变量 `MSE_SERVER` → 仓库相对路径 `<repo>/build/mse_server.exe`
  → `PATH`。三者都找不到会报"找不到 mse_server.exe"。
- 仅 `ui_playbook.py` 需要额外准备:删库重启 `start_mes.bat`,再 `run_demo.bat`
  (即 `mse_demo --server 127.0.0.1:18080`)灌入"昨日"背景数据。

### 单本跑法

```bash
python mse/tools/pb2_supply_chain.py      # 自管理,随时可跑
python mse/tools/pb3_quality_compliance.py
python mse/tools/pb4_plan_disruption.py
python mse/tools/pb5_ops_integration.py
python mse/tools/ui_playbook.py 127.0.0.1:18080   # 外部模式,需先灌背景
```

逐条打印 `[OK]`/`[FAIL]`,末尾总账 `剧本验证:checks=N fails=M`。
**退出码:0 = 全部符合预期,1 = 有 FAIL**(可直接进 CI)。

### 一键回归

```bash
python mse/tools/run_all_playbooks.py                  # 只跑四本自管理(pb2~pb5)
python mse/tools/run_all_playbooks.py 127.0.0.1:18080  # 加跑 ui_playbook(需先灌背景)
```

顺序执行、逐本汇总 `PASS/FAIL (exit=N)`,任一失败总退出码为 1。

### 自管理机制(pb2~pb5)

每本自管理剧本 `with Server() as s:` 自带全套生命周期,不碰你正在跑的服务器:

- **自动起停**:`Popen` 拉起 `mse_server.exe --port P --db T/a.db --voxel-db T/av.db`;
- **临时库**:`tempfile.mkdtemp` 独立目录,演完 `cleanup()` 整个删掉,零残留;
- **随机端口**:`socket` 探测空闲端口,与 18080 的常驻服务器互不干扰;
- **就绪轮询**:`GET /meta/views` 直到 200 或 10s 超时,启动即退出会把服务器日志
  路径抛出来;
- **崩溃恢复**:`s.stop()` 终止进程、`s.restart()` 用同一 db 重启(新随机端口),
  pb5 靠它做停库重放验证。

## 3. playbook_lib 公共库与 Server 类

`mse/tools/playbook_lib.py` 两份职责:

**HTTP 帮助函数**(与 H5 界面发同一批请求,默认凭证 `ui-token`):

| 函数 | 用途 |
|---|---|
| `set_base(base)` | 绑定请求目标(`host:port` 或 `http://…`) |
| `post(type_, id_, kvs, actor, space=None, token=…, **syskeys)` | 发起事件候选;kvs 是扁平属性写入;syskeys 可带 `space/time/evidence/corrects/idempotency_key`,或 `writes={目标:{键:值}}` 显式多目标形态 |
| `api(method, path, body, token)` / `view(vid, **params)` / `view_text(vid)` | 裸请求 / 视图 JSON / 视图原文(逐字节比对用) |
| `drain()` | `POST /drain` 异步队列手动落账 |
| `row_of(v, rid)` / `btn_of(row, type)` / `action_of(v, type)` | 取行 / 取行上按钮(验 presets/options)/ 取视图级发起动作 |
| `events_all(limit)` / `events_of(type_)` | 事件流全量 / 按类型过滤 |
| `node_ids(v)` / `has_edge(v, from_, key, to)` | 遍历图节点集合 / 边断言 |

**校验计数**:`check(ok, label, detail)` 打印 `[OK]/[FAIL]` 并累计;
`banner(title)` 打印幕头;`summary()` 打印总账并 `sys.exit(0/1)`。剧本只 import,
不自行计数。

**Server 类**:见 §2"自管理机制"——`__init__` 即启动,`stop()/restart()/cleanup()`,
支持 `with` 语法。

### 怎么写第六本剧本(骨架)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# mse/tools/pb6_xxx.py —— 剧本6:×××(剧情一句话)
import json
from playbook_lib import (Server, set_base, post, view, row_of, btn_of,
                          action_of, events_of, check, banner, summary,
                          node_ids, has_edge)

with Server() as s:                 # 自管理:临时库+随机端口;打外部服务器则
    set_base(s.base)                # 改为 set_base("127.0.0.1:18080") 并去掉 with
    banner("剧本6:×××")

    print("\n[第一幕] ×××")
    r = post("OrderReceived", "VIN-XX01",
             {"车型": "SUV-A", "订单状态": "接收"}, "planner-wang")
    check(r["status"] == "settled", "1.1 接收订单", json.dumps(r, ensure_ascii=False))

    v = view("V-ORDER-A1")
    check(row_of(v, "VIN-XX01").get("订单状态") == "接收", "1.2 A1 行状态=接收")
    # 拦截断言:r["status"] == "rejected" and any("R-XXX" in x for x in r["violations"])
    # 崩溃恢复:s.restart(); set_base(s.base) 后逐比特比对(view_text / events_all)

summary()   # 打印总账并 sys.exit(0/1);忘了调它,退出码永远是 0
```

纪律:①每个预期结果一条 `check`,标签带幕.步编号,与人工手册步号对齐;
②断言到**值**(行、键、边、violations 文案),不断言"没报错";
③被拦候选顺手验零污染(事件流数量不增);④把脚本加进
`run_all_playbooks.py` 的 `SELF_MANAGED` 列表即纳入一键回归。

## 5. 剧本抓到的系统 bug(剧本即回归网的价值)

| bug | 症状 | 修复 | 抓到它的剧本 |
|---|---|---|---|
| 订单状态写授权缺漏 | `OrderRevokeReversed`(撤单恢复)写"订单状态"被 L2 拒——修正类型不能写它要修正的属性,撤单永远恢复不了 | seeds 把 `OrderRevokeReversed` 补进"订单状态"的 writers(commit `defe0df`) | pb4 第一幕(撤单/恢复/重接收) |
| BOM 空值 500 | 无 BOM 工位上扫料,规则求值抛 RuleError,HTTP 直接 500(应是干净的拒绝回执) | 规则求值 fail-closed:RuleError 转为 rejected 不再 500;R-MAT-PKE 对无 BOM 工位明确拒绝(commit `7b4a52d`) | 防错链路回归(B4/R-MAT-PKE) |
| libwinpthread 依赖 | 自管理 Server 拉起的 mse_server 在没装 MinGW 的干净 Windows 上缺 DLL、启动即退出,剧本全灭 | 全静态链接 `-static`,exe 零运行时依赖;release 包另附带 UCRT DLL(commit `7b4a52d`/`c71145c`) | pb2~pb5 的自管理 Server(临时进程拉起路径) |

三个 bug 分属三层:**立法层**(字典写授权)、**执行层**(异常到回执的翻译)、
**交付层**(二进制可移植性)——剧本网兜住的正是"单元测试各自为证、拼起来才暴露"
的那类缝。每次修完 bug,剧本原样重跑即防复发。
