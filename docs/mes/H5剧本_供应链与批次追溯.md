# H5 剧本:供应链与批次追溯(pb2 人工版)

> **定位**:面向 H5 验证台的剧本式操作说明,是自动化剧本
> `mse/tools/pb2_supply_chain.py`(50 项校验)的**人工操作版**——人照着 UI 能点出
> 与脚本相同的结果。全程只用浏览器界面(不发 API、不碰数据库),每步给出**预期结果**
> 与**结果说明**(这步验证了什么系统机制)。
> **剧情**:清晨到货,库管登记三只物料、下达工位 BOM;中央库与线边库分仓记账;
> 四类拉动单各归各看板;批次绑定上车,一次错绑、作废、重绑,全程留痕;
> 最后从批次反向追溯回车辆与供应商。
> **配套**:主流业务的一天见《H5业务流模拟操作手册.md》;异常/边界专项见
> 《H5人工验证测试方案.md》;脚本化回归见《剧本自动化回归.md》。

> **UI 与脚本的两处形态差异**(先读,后面不再重复):
> ① 脚本的 `BatchBoundToVIN`/`BindingVoided` 用显式 writes **一条事件双目标各写各的键**
> (一次发生、双向写);H5 表单是扁平键,一次事件对所有目标写同一组键值,因此本手册
> **拆成两笔**(VIN 侧一笔、批次侧一笔),终态与遍历图完全一致。
> ② 脚本作废时用空串清空关系(空串=没有关系);H5 表单**空值 = 不提交该键**,写不了
> 空串,因此界面路径是"作废留痕(corrects)+ 重绑覆盖",终态一致。

## 结果总览(演完后的系统状态)

- 物料/批次/订单/拉动单/库存账本全部是本体,属性逐事件演化,无一处"改记录";
- 四类拉动看板与线边库视图演示两种读侧收敛:**规则决定行**(R-VIEW-*)与**时空切片**(spacetime);
- 追溯图正反向可走,错绑/作废/重绑三段带 corrects 因果链永存;
- 判定口诀同前:**界面上能点的,API 就能结算;界面上被拦的,API 也结算不了**。

## 常见问题

- **BOM清单/物料需求怎么填**:list 型属性是 JSON 文本框,填 `["MAT-SC01","MAT-SC02"]` 这样的数组,格式错了表单就地提示"JSON 解析失败"。
- **批次绑定/VIN绑定填什么**:ref 型属性,填对方本体 id(带本体候选下拉,可手输)。
- **遍历视图红了/空白**:V-TRACE-B5 需要 entity;不填时显示参数引导页,可点本体快捷按钮。
- **数据想重来**:停服务器删两个 db 文件即可(本剧本不依赖 demo 背景)。
